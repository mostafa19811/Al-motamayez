الصفحات: index.html (الرئيسية والتواصل) · exams.html (الاختبارات) · register.html (بيانات الطالب) · exam.html (الاختبار والنتيجة)
التدفق: الاختبارات ← بيانات الطالب (الاسم/الجوال/الصف من الأول إلى الثالث الثانوي) ← الاختبار بمؤقت ← النتيجة الكلية ودرجة كل مهارة وشرح الحل ← أزرار العودة للاختبارات وتعديل البيانات.

1) بيانات الموقع ووسائل التواصل: site.config.json (الاسم، الوصف، المعلومات، روابط التواصل، الباركود، التذييل، sheetUrl).
2) حفظ بيانات الطلاب: google-apps-script.gs ← انشره Web app ← ضع رابط /exec في sheetUrl.
3) الاختبارات: ابنِها في exam-editor.html ثم "تنزيل حزمة الموقع" وانسخ مجلدي data و img فوق مجلد الموقع.
   الحزمة تتضمن: data/exams/{الفرع}-{المهارة}-{الرقم}.json و data/exams/index.json (فهرس الاختبارات الذي تقرأه صفحة الاختبارات) و data/skills.json.
   المحرر يحتفظ بفهرس تراكمي على جهازك؛ إن غيّرت الجهاز فارفع index.json الحالي من زر "إدارة المهارات والفهرس".
4) احذف النموذج التجريبي: data/exams/quant-demo-1.json وسطره في index.json.
الموقع يقرأ JSON بـ fetch فيعمل على GitHub Pages (لا يعمل بفتح الملفات مباشرة من الجهاز).
لا تضف إلا أسئلة تملكها أو مرخّصة لك.

كلمة مرور الدخول:
1) افتح password-tool.html (من موقعك بعد الرفع أو عبر خادم محلي)، اكتب كلمة المرور، وانسخ السطر "accessHashes".
2) ألصقه في site.config.json (يمكن وضع أكثر من بصمة لأكثر من كلمة). القائمة الفارغة = الموقع مفتوح بلا كلمة مرور.
3) الرئيسية مفتوحة للجميع؛ الاختبارات وبيانات الطالب والاختبار تتطلب كلمة المرور. غيّر البصمة لإيقاف كلمة قديمة (تنتهي صلاحية الدخول المحفوظ عند الطلاب).
تنبيه: الاستضافة ثابتة (GitHub Pages) فالحماية على مستوى الصفحات؛ ملفات data/exams/*.json يمكن لمن يعرف رابطها تنزيلها مباشرة. للحماية الكاملة يلزم تشفير ملفات الاختبارات.
